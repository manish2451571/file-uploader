# Drag & Drop File Uploader

## Run

```
pip install flask flask-cors werkzeug
cd FileUploader/Backend
python server.py
```

Open `FileUploader/Frontend/index.html` in your browser.

## Features
- Drag & drop or browse to select files
- Multi-file upload queue with real progress bars
- Grid / List view toggle
- Search uploaded files
- Download & delete files
- Toast notifications
- Supports: PNG, JPG, PDF, DOC, TXT, MP4, ZIP, CSV, XLSX
- Max 10MB per file
